# اپ ورزشکار گُردیار

اپ رسمی ورزشکاران گُردیار با Expo و React Native ساخته شده و روی Android،
iOS و وب اجرا می‌شود.

## امکانات نسخه پایه

- ورود و ثبت‌نام اختصاصی ورزشکار
- نگهداری امن نشست کاربر روی گوشی
- جستجوی باشگاه‌های تاییدشده
- گُردیار Pass برای ورود مکانیزه
- بخش برنامه تمرینی، تغذیه و مشاوره
- پروفایل، عضویت‌ها، پرداخت‌ها و مدارک ورزشی

## اجرا

از پوشه `mobile`:

```bash
npm install
copy apps\athlete\.env.example apps\athlete\.env
npm run athlete
```

سپس QR نمایش‌داده‌شده را با Expo Go اسکن کنید. برای قابلیت‌های بومی مانند
NFC باید Development Build ساخته شود.
