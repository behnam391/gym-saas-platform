# سامانه هوشمند مدیریت باشگاه‌های ورزشی

پلتفرم چندمستاجری فارسی و RTL برای مارکت‌پلیس باشگاه‌ها، مدیریت اعضا، مربیان، متخصصان تغذیه، حضور و غیاب، شلوغی زنده، بوفه، تیکت و پیشنهادهای هوش مصنوعی.

## ساختار پروژه

- `frontend/`: رابط کاربری Next.js، داشبوردهای نقش‌محور و BFF امن مدیریت نشست
- `backend/`: API ماژولار NestJS، Prisma، RBAC، صف اعلان و WebSocket
- `backend/prisma/`: مدل کامل داده، migration پایه و سیاست‌های Row-Level Security
- `deploy/`: استقرار Docker Compose شامل PostgreSQL، Redis، API، worker، فرانت‌اند و Nginx

## اجرای محلی

1. فایل‌های `backend/.env.example` و `frontend/.env.example` را به فایل محیط محلی کپی و مقادیر لازم را تنظیم کنید.
2. در پوشه `backend` وابستگی‌ها را نصب، migration را اجرا و سپس API را اجرا کنید.
3. در پوشه `frontend` وابستگی‌ها را نصب و برنامه را روی پورت ۳۰۰۱ اجرا کنید.

جزئیات استقرار در `DEPLOY-GUIDE.md` و طراحی دیتابیس در `database-design.md` قرار دارد.

## وضعیت فعلی

- ساخت production فرانت‌اند و بک‌اند موفق است.
- آزمون‌های واحد امنیت، احراز هویت، ایزولیشن context، بوفه و AI پاس می‌شوند.
- نشست مرورگر با کوکی `httpOnly`، چرخش refresh token و هدایت نقش‌محور پیاده‌سازی شده است.
- migration اولیه و RLS مستقیم و غیرمستقیم برای جلوگیری از اختلاط داده باشگاه‌ها وجود دارد.
- جریان درخواست عضویت از صفحه باشگاه تا ایجاد عضویت در انتظار تایید بیمه متصل است.

برای اجرای آزمون واقعی RLS، یک PostgreSQL آزمایشی با سیاست‌های `backend/prisma/rls-policies.sql` لازم است.
